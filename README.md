# Причал

Облік стоянки човнів і щомісячна оплата для човнової станції
поруч із базою відпочинку «Темп Дніпра».

Клієнт бачить своє місце й рахунок і платить за QR прямо зі свого банку.
Адміністратор бачить, хто де стоїть і хто скільки винен.

## Подивитись

**[fominadesigns.github.io/prychal](https://fominadesigns.github.io/prychal/)**

| [CRM](prototype/crm.html) | календар стоянки: місця зверху, числа зліва, клік — картка човна |

## Стан

Коду ще немає. Це матеріали для показу й узгодження.

**Усі цифри, імена, номери човнів і телефони на сторінках — вигадані
заглушки.** Справжні тарифи й дані з'являться після відповідей на бриф.
